# Diário de Estudos

Caderno online para estudantes de qualquer área: o aluno cria uma pasta para cada matéria, guarda textos, frases, links de vídeos e de slides, e depois estuda por um resumo montado pelo próprio site.

Projeto final da disciplina de Front-end.

Integrantes

- Maria Eduarda Fernandes
- Luan Rhikelmy

## Tecnologias

- Next.js (React) com CSS feito à mão
- Zustand (estado global)
- TanStack Query (busca e alteração de dados)
- Supabese (back-end e banco de dados)
- Vercel (publicação)

## Como rodar o projeto

1. Instale o [Node.js](https://nodejs.org) (versão 20 ou mais nova).
2. Baixe o projeto: `git clone https://github.com/eduardamfz/diario-de-estudos.git`
3. Entre na pasta: `cd diario-de-estudos`
4. Instale as dependências: `npm install`
5. Rode o site: `npm run dev`
6. Abra http://localhost:3000 no navegador.
